# The interface around the model

!!! guiding "The question this chapter answers"
    The model works. Now — what does a person actually touch, and what happens when it is wrong?

!!! note "🚧 Work in progress"
    This chapter is still being written. The teaching week it belongs to is planned; the prose isn't here yet. It lands before the week it is needed.

**What it will cover.** The part of machine learning designers are responsible for and almost nobody teaches. Showing uncertainty honestly instead of rounding it into a confident answer; designing for error so someone can notice, undo, appeal or route around a wrong prediction; explaining a prediction without lying about how it was made; and asking what your system becomes after a year of its own output feeding back into it — the loop from Chapter 11, closed.
