# The loop: interfaces that teach models

!!! guiding "The question this chapter answers"
    What is an interface teaching the model behind it — and what does it mean for a machine to "learn" at all?

!!! note "🚧 Work in progress"
    This chapter is still being written. The teaching week it belongs to is planned; the prose isn't here yet. It lands before the week it is needed.

**What it will cover.** Supervised learning in plain language (features → model → prediction), and the loop every ML product runs on: the interface shapes behaviour, behaviour becomes training data, the retrained model reshapes the interface. Algorithmic affordances — the heart, the skip, the swipe, the dwell — as labelling tools handed to users who were never told. Reading a "For You" feed from the outside with the four teardown questions.
