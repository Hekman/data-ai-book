# Classification by rules: decision trees

!!! guiding "The question this chapter answers"
    How does a model decide which category something belongs to, when the rule is one it wrote itself?

!!! note "🚧 Work in progress"
    This chapter is still being written. The teaching week it belongs to is planned; the prose isn't here yet. It lands before the week it is needed.

**What it will cover.** From predicting a number to predicting a category. The decision tree as a flowchart the model wrote by looking at examples: how a split is chosen, why a deeper tree is not a better tree, and how to explain one prediction by following its splits out loud. Then the trap in that legibility — proxy features, and the two ways a classifier can be wrong, which almost never cost the same. Teardown: the spam folder and its "not spam" button.
